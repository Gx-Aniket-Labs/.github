## 👋 About Us

**GX Aniket Labs** is a student-led developer community focused on learning, building, and collaborating on technology-driven projects.

We bring together students and aspiring developers who are passionate about programming, software development, problem-solving, and innovation.

Our goal is to turn ideas into practical projects while creating an environment where developers can learn from each other and grow together.

## 🎯 Our Mission

| Principle | What We Believe |
|---|---|
| Learn | Continuously improve technical and problem-solving skills. |
| Build | Develop practical projects and real-world applications. |
| Collaborate | Work together, share knowledge, and support each other. |
| Innovate | Explore new technologies and creative solutions. |
| Grow | Build experience through consistent development. |

## 💻 Areas of Focus

- Full Stack Web Development
- Java & Data Structures and Algorithms
- Artificial Intelligence & Machine Learning
- Open Source Development
- Software Engineering
- Creative and Experimental Projects

## 🚀 Founder Projects

The following projects were developed by our founder, **Aniket Sundriyal**. They showcase practical experience in software development, web technologies, and machine learning.

| Project | Description | Live Demo | Source Code |
|---|---|---|---|
| **Integrated Logistics Intelligence Platform** | Full-stack logistics platform featuring shipment management, live tracking, ETA calculation, and delivery monitoring. | [Live Demo](https://integrated-logistics-intelligence-p.vercel.app/) | [GitHub](https://github.com/GxAniket/Integrated-Logistics-Intelligence-Platform) |
| **Todo App** | A productivity and task management application built with React.js. | [Live Demo](https://todo-app-two-sigma-85.vercel.app/) | [GitHub](https://github.com/GxAniket/Todo-App) |
| **Music Player** | A browser-based music player with interactive controls and audio playback features. | [Live Demo](https://gxaniket.github.io/music-player/) | [GitHub](https://github.com/GxAniket/music-player) |
| **Encryptor & Decryptor** | A browser-based encryption and decryption tool. | [Live Demo](https://gxaniket.github.io/encryptor-decryptor-version-1/) | [GitHub](https://github.com/GxAniket/encryptor-decryptor-version-1) |
